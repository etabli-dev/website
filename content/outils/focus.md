## What it does

Focus records focused work by category, with weekly targets, local history and
session statistics.

- Optional FlowSavvy task progress.
- Calendar reminders through CalDAV on Android and desktop, and through the
  system calendars on iOS.

## Where it stands

An Android development build (v0.1.0) is on GitHub Releases. Unsigned iOS
Release builds have been verified. The desktop preview covers Linux, Windows and
macOS. Notification behaviour still needs device acceptance.
