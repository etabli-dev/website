## What it does

Every move is recorded on an explicit timeline. You can scrub back to any past
move and branch into a parallel universe by playing differently, so a game is a
tree of universes, not a single line.

- Replay, alternative branches, an AI opponent and probability views.
- Runs entirely offline.

## Where it stands

An Android development build (v0.1.0) is on GitHub Releases. The browser and
Tauri desktop builds run from source.
