## What it does

A tesseract of 256 cells with 520 winning lines: tic-tac-toe with every
extra dimension the screen allows.

- Runs entirely offline.

## Where it stands

An Android development build (v0.1.0) is on GitHub Releases. The browser and
Tauri desktop builds run from source.
