## What it does

Plume is a categorised reference and snippet picker for typesetting commands:
commands, Greek letters, maths operators, formatting, environments and
bibliography.

- 123 commands and 10 snippets are bundled for offline use.
- Search, a preview pane, copy and favourites.

## Where it stands

A signed Android development APK is on GitHub Releases. The desktop preview's
Linux `.deb` has been built and launch-tested. Windows and macOS packages are
built only in CI.
